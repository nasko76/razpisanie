# Laravel Roles + Plans Starter

Това е прост Laravel проект starter с:
- Login / Auth
- Laravel Breeze или стандартната Laravel auth
- Spatie Permission
- Роли: admin, manager, user
- Permissions: view plans, create plans, edit plans, delete plans, manage users
- Plan resource
- Admin interface за управление на роли и permissions

## Изисквания

- PHP 8.2+
- Composer
- MySQL / SQLite / PostgreSQL
- Node.js (ако използваш frontend build)
